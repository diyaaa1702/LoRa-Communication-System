# LoRa Communication System

A secure, low-latency communication system using LoRa (Long Range) technology.

## Overview
This project was part of a team collaboration between July 2024 – November 2024, focused on developing a communication system using LoRa modules for encrypted and reliable messaging.

## Key Contributions
- Developed a secure communication flow using Arduino Uno and LoRa transceivers.
- Focused on low-latency data transmission between nodes.
- Assisted in hardware testing, debugging, and communication reliability improvements.

## Technologies Used
- Arduino Uno
- LoRa SX1278 Modules
- C/C++
- Serial Communication
- Basic Encryption

## Project Status
🛠️ Prototype tested and operational in a lab environment. Future versions aim to include GPS and advanced authentication.
